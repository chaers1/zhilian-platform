
## 链接流程
```bash
# 查看ip
ip a ->>  192.168.0.120/24   /在开发机的xshell中链接 这个ip地址

# 查看ssh服务是否开启
sudo systemctl status ssh   # 查看状态
sudo systemctl start ssh    # 如果未启动
输入用户名和密码进行链接
```
# 拉取代码
```bash
# 进入用户目录
cd ~

# 克隆项目
git clone https://github.com/chaers1/zhilian-platform.git

# 进入项目目录
cd zhilian-platform

# 查看文件
ls -la
```

# docker 
```bash
# 检查 Docker 是否已安装
docker --version
# 安装docker命令
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER --》执行后需要**退出 Xshell 重新连接**，权限才会生效。
# 检查 Docker Compose
docker compose version
# 如果没安装
sudo apt update
sudo apt install docker-compose-v2 -y
# 一键启动所有服务
docker compose up -d --build
# 查看运行状态
docker compose ps -》所有服务状态应该是 `Up`
# 查看日志
docker compose logs -f -> ctrl + c 退出日志

```
