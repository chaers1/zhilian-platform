## user应用接口
| 接口     | 方法   | 路径                 | 说明                  |
| ------ | ---- | ------------------ | ------------------- |
| 用户注册   | POST | api/users/register | 新用户注册该应用不经token验证   |
| 用户登录   | POST | api/users/login    | 用户登录应用不经token验证     |
| 用户退出   | POST | api/users/logout   | 退出登录应用接口，需要token验证  |
| 用户个人中心 | GET  | api/users/profile  | 用户个人中心接口，需要token验证, |
| 用户个人中心 | POST | api/users/profile  | 用户个人中心更改信息接口        |

## crawler 应用 爬虫页面应用接口
| 接口            | 方法   | 路径                                           | 说明             |
| ------------- | ---- | -------------------------------------------- | -------------- |
| 爬虫启动停止        | POST | api/crawler/spider_start                     | 爬虫启动和停止token验证 |
| 爬虫启动后实时抓取数据接口 | GET  | api/crawler/spider/<str:spider_name>/status/ | 爬虫启动后实时抓取数据接口  |
### api/crawler/spider_start
```JSON
/* 前端请求 */
{

	spider_type: spiderType,// 爬虫类别
	action: action, // 启动与停止，start 与 stop
	source: source // 默认是那一只爬虫

}

/* 后端返回 */

{  
    'status': 'success',  
    'message': f'{action} 指令已发送',  
    'task_id': task.user_id,  
    'command': command  
}

{  
    'status': 'error',  
    'message': '无效的 JSON 数据'  
}
{  
    'status': 'error',  
    'message': str(e)  
}
```
### api/crawler/spider/<str:spider_name>/status/
```json
/* 前端 */

{
 spider_name -> 爬虫的名字
}

/* 后端返回 */

{  
    "spider_name": spider_name,  
    "status": status,  
    "start_time": start_time,  
    "current_count": int(current_count),  
    "total_expected": int(total_expected),  
    "progress_percent": progress_percent,  
}

{  
    "success": False,  
    "message": f"获取状态失败: {str(e)}"  
}
```
## FastAPI -- 8001

| ------------ | --- | ------------------------------------------ | ------------------------- |
| 总体概览页面数据展示接口 | get | /api/crawler/dashboard/stats               | 需要token验证，需要用户数据模型和爬虫数据模型 |
