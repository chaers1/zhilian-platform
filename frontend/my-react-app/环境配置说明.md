# 环境配置说明文档

## 📋 快速开始

### 开发环境切换

#### Windows 开发环境

```bash
# 复制配置文件
copy .env.development .env.local

# 编辑 .env.local 根据需要修改端口
# 确保 FastAPI 端口与实际启动的端口一致

# 重启前端服务
npm run dev
```

#### Ubuntu 开发环境

```bash
# 复制配置文件
cp .env.ubuntu .env.local

# 编辑 .env.local 根据需要修改端口

# 重启前端服务
npm run dev
```

## 📁 配置文件说明

| 文件 | 说明 | 推送Git |
|------|------|---------|
| `.env` | 默认基础配置（不常用） | ✅ |
| `.env.development` | Windows开发环境模板 | ✅ |
| `.env.ubuntu` | Ubuntu开发环境模板 | ✅ |
| `.env.local` | **当前使用的配置**（本地专属） | ❌ |

## 🚀 常用端口配置

### Django 后端
- 常用端口：**8000**
- 备用端口：8001, 8002

### FastAPI 后端
- 常用端口：**8001**
- 备用端口：**8081**, 8002, 8003, 8888

## 💡 端口被占用时的解决方法

### 1️⃣ 查找占用端口的进程

#### Windows:
```bash
netstat -ano | findstr "8001"
taskkill /F /PID <进程ID>
```

#### Ubuntu:
```bash
lsof -i :8001
kill -9 <进程ID>
```

### 2️⃣ 更换端口启动后端

#### FastAPI:
```bash
# 使用 8081 端口
uvicorn app.main:app --reload --port 8081
```

#### Django:
```bash
# 使用 8002 端口
python manage.py runserver 0.0.0.0:8002
```

### 3️⃣ 更新前端配置

修改 `.env.local` 中的端口：

```bash
VITE_DJANGO_PORT=8002
VITE_FASTAPI_PORT=8081
```

然后重启前端服务 `npm run dev`

## ⚠️ 注意事项

1. **每次修改 .env.local 后必须重启前端服务**
2. **不要把 .env.local 推送到 Git**
3. **首次克隆仓库需要手动创建 .env.local**
4. **确保后端服务已启动才能访问**

## 🎯 完整启动流程

### Windows 开发环境

```bash
# 1. 启动 Django 后端
cd backend
python manage.py runserver 0.0.0.0:8000

# 2. 启动 FastAPI 后端（新终端）
cd backend/FastAPIProject
uvicorn app.main:app --reload --port 8081

# 3. 启动前端（新终端）
cd frontend/my-react-app
npm run dev
```

### Ubuntu 开发环境

```bash
# 1. 启动 Django 后端
cd ~/zhilian-platform/backend
python manage.py runserver 0.0.0.0:8000

# 2. 启动 FastAPI 后端（新终端）
cd ~/zhilian-platform/backend/FastAPIProject
uvicorn app.main:app --reload --port 8081

# 3. 配置环境文件
cd ~/zhilian-platform/frontend/my-react-app
cp .env.ubuntu .env.local
# 编辑 .env.local 修改端口（如果需要）

# 4. 启动前端
npm run dev
```
